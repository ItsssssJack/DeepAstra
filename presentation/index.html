Sources & methodology

Checked 13 September 2026. Artificial Analysis Intelligence Index v4.3, maximum reasoning for all three models. Published average API cost per attempted task: Astra $3.26, Sol $1.99, DeepSeek $0.27. These are weighted benchmark costs, not our study receipts; our business run requested DeepSeek high. Astra comparison ↗ · Sol comparison ↗

AA counts input, cached input, reasoning and answer tokens. Repricing the same DeepSeek workload at the official half-price off-peak tariff gives $0.135 per attempt: $3.26 ÷ $0.135 ≈ 24.1×. At published peak rates: $3.26 ÷ $0.27 ≈ 12.1×. Off-peak is an estimate, not a fresh benchmark. Results are not adjusted for equal quality or success. Hybrid savings must also include Astra planning/review, retries and tool costs. App subscriptions are separate. DeepSeek rates ↗

Output-token price: Astra $50/M versus DeepSeek $0.60/M off-peak, or 83.3×. Uncached input: $10/M versus $0.15/M, or 66.7×. Max reasoning uses the same Astra tariff; it changes token usage. Standard API pricing with at most 272K input tokens per request; Fast, Batch/Flex and long-context rates differ. Astra rates ↗

The released weights and code are MIT licensed, roughly 511GB on disk. Running locally does not inherently reduce capability when weights, precision, settings and tools are held constant; exact parity for third-party builds is unverified. vLLM sizes around 614GB GPU memory including headroom and gives 4×GB200 or 8×H200 examples, not universal minimums. Model release ↗ · Memory sizing ↗

The 5090 developer reports 5.1 tokens/s on new content and 21 tokens/s for cached expert reuse; we have not reproduced either. The $12,782 retailer example has a 500GB Gen4 SSD, which is insufficient: budget extra for at least 1TB, preferably 2TB, fast Gen5 NVMe and compatible software. It is a comparable hardware listing, not the tested system or the cheapest build. The H200 system is listed at $296,549; no V4.1 speed measurement for that exact server was verified. Taxes, energy and setup are extra.

A separate experimental M3 Ultra 512GB build reports 14.6 tokens/s at 1,000 tokens with about 425.9GiB memory use. It applies additional compression; matching the API's quality is unverified. We have not verified a current purchase price for that Mac configuration. Mac test ↗
